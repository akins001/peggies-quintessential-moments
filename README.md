# Peggies Homepage

Build the main homepage for Peggies Events, a mature, premium full-service event planning and design firm in Abuja, Nigeria. Use the attached package image as visual reference and include it in a Packages section; derive a refined palette from it: cream/white, warm gold/champagne, deep espresso brown, soft muted floral tones. Avoid reliance on headshot for now, but create a graceful founder/about section with a clearly designed placeholder for Peggy Adugba's headshot that can be replaced later. Brand: Peggies Events / Peggies Exclusive Events. Tagline: “Crafting Quintessential, Magical Moments.” Core copy: Peggies Events transforms milestone occasions into unforgettable, meticulously curated experiences, offering comprehensive planning, production, and high-end decoration for weddings, corporate functions, gala dinners, and luxury social celebrations. Services: Event planning and coordination; Event decoration; Weddings; Engagements & proposals; Bridal & baby showers; Birthdays; Social events; Corporate events; Dinners & festivals. About Peggy: certified event professional in Abuja, passionate about translating visions into “The Quintessential Magical Experience.” Leads every event from concept to setup and execution; vision to establish Peggies Events centers globally. Location: F01 Charlottes Adesiyan Street, Abuja. Include prominent WhatsApp/call booking CTA based on package artwork phone 09134153272. Create sections: refined hero, social proof/intro, service offering grid, featured celebrations/portfolio section with tasteful placeholders ready for later work photos, package preview using supplied image, founder story, location/contact/booking, and rich elegant footer. Navigation should support scrolling sections and be mobile responsive. Use sophisticated editorial typography, a premium event-luxury feeling, restrained motion, accessible contrast. Main page only. Prepare the structure so an admin-managed gallery can be added later, but do not build the admin page yet.
